# DATA6000
South Australia is rolling out 40km/h speed zones near about 160 schools, funded under a $168M National Road Safety Program. The government has given general criteria (road speed, traffic volume, crash history) but hasn't published how schools are actually scored or ranked.

This project builds a data-driven risk model using SA crash, casualty and traffic volume data to independently rank schools by crash/traffic risk, then compares this against the actual rollout status to see whether the current selection is risk-aligned or if some high-risk schools are being left out.
